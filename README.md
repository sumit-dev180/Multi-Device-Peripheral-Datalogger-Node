# Multi-Device Peripheral Datalogger Node

A multi-device embedded system simulation using I2C OLED display and SPI flash memory for timestamped sensor data logging.

## Project Overview

The Multi-Device Peripheral Datalogger Node is an embedded systems project designed and simulated in Proteus. It demonstrates sensor data communication, real-time data display, and external memory logging using two communication protocols: I2C and SPI.

The system displays sensor readings on an OLED display through I2C communication while simultaneously storing timestamped sensor data arrays in external SPI flash memory.

## Objectives

- Design and simulate a multi-device embedded system in Proteus.
- Interface a sensor with a microcontroller.
- Display sensor readings on an OLED using I2C communication.
- Interface external SPI flash memory.
- Store timestamped sensor data arrays in external flash memory.
- Demonstrate simultaneous data display and data logging.

## Working Principle

1. The sensor collects data and sends it to the microcontroller.
2. The microcontroller processes the sensor readings.
3. Sensor readings are transmitted to the OLED display using I2C.
4. Simultaneously, timestamped sensor data arrays are stored in external SPI flash memory.
5. Both communication interfaces operate together to provide data display and logging.
